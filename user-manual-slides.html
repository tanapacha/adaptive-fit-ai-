SLIDE 2 • หน้าหลัก (TODAY DASHBOARD)

ภาพรวมพลังงานและเป้าหมายรายวัน

หน้าแรกสรุปทุกอย่างที่ต้องรู้ในวันเดียว ทั้งแคลอรี่ที่กินได้, โปรตีนเป้าหมาย และสถานะการฝึก

  • 1
    วงแหวนพลังงาน (Energy Ring) ดูแคลอรี่ที่กินไปแล้วเทียบกับเป้าหมายรายวัน พร้อมแคลอรี่คงเหลือแบบเรียลไทม์
  • 2
    สารอาหารหลัก (Macros: P / C / F) ติดตามโปรตีน คาร์โบไฮเดรต และไขมัน แยกสีชัดเจนเพื่อคุมรูปร่างให้ตรงเป้า
  • 3
    ปุ่มลัดเข้าสู่โหมดฝึก & สแกนอาหาร กดปุ่มลัดบนการ์ดเพื่อกระโดดไปบันทึกมื้ออาหารหรือเริ่มฝึกได้ทันที
หน้าจอแอปจริง (เลื่อน/กดทดสอบได้)
SLIDE 3 • โหมดฝึกซ้อม (WORKOUT & REST TIMER)

บันทึกเซตฝึก & ตัวจับเวลาพักเซตอัตโนมัติ

ออกแบบมาเพื่อการเล่นดัมเบลโดยเฉพาะ พร้อมตัวช่วยคุมเวลาพักระหว่างเซต

  • 1
    เลือกตารางฝึกประจำวัน สลับวันฝึก (เช่น Push / Pull / Legs / Full Body) ระบบจะแสดงท่าดัมเบลที่ต้องเล่นในวันนั้น
  • 2
    กรอกน้ำหนัก (kg) & จำนวนครั้ง (Reps) บันทึกน้ำหนักที่ใช้จริงในแต่ละเซต แล้วกดติ๊กถูกเมื่อเล่นจบเซต
  • 3
    Rest Timer อัจฉริยะ (+15วิ / -15วิ / เสียงเตือน) แถบจับเวลาด้านบนจะเริ่มนับถอยหลังอัตโนมัติ กด -15วิ / +15วิ ปรับเวลาได้ทันที และมีเสียง+สั่นเตือนเมื่อครบเวลา
หน้าจอแอปจริง • แถบจับเวลาด้านบน
SLIDE 4 • โภชนาการ (AI SCAN + วัตถุดิบ)

บันทึกอาหารได้ทั้งถ่ายรูป พิมพ์ชื่อ และใส่วัตถุดิบ

รองรับทั้งการสแกนด้วย Gemini AI และการคำนวณทันทีแบบไม่ต้องใช้รูปภาพ

  • 1
    ถ่ายรูปอาหาร (AI Scan) อัปโหลดรูปอาหารแล้วกด "ให้ AI คำนวณแคลอรี่" ระบบจะแยกวัตถุดิบและสารอาหารให้อัตโนมัติ
  • 2
    เลือกวัตถุดิบด่วน หรือพิมพ์เพิ่มเอง กดปุ่มวัตถุดิบ (+ อกไก่, + ไข่ไก่, + แซลมอน, + ข้าวโอ๊ต ฯลฯ) หรือพิมพ์ชื่อวัตถุดิบ/เมนูอาหารเอง
  • 3
    คำนวณแคลอรี่ทันที (ไม่ต้องใช้รูป) กดปุ่มสีเขียว "คำนวณจากชื่อ/วัตถุดิบ (ไม่ต้องใช้รูป)" ระบบจะประเมิน kcal / P / C / F ให้แก้ไขและบันทึกได้ทันที
หน้าจอแอปจริง • โหมดอาหารและวัตถุดิบ
SLIDE 5 • คาร์ดิโอ & ความก้าวหน้า

ติดตามคาร์ดิโอ น้ำหนักตัว และสถิติ

เห็นพัฒนาการของตัวเองอย่างชัดเจน ทั้งการเผาผลาญและแนวโน้มน้ำหนักตัว

  • 1
    บันทึกคาร์ดิโอ (Cardio Rounds) ติ๊กจำนวนรอบที่ทำได้ หรือระบุเวลา/แคลอรี่ที่เผาผลาญเพิ่มในแต่ละวัน
  • 2
    บันทึกน้ำหนักตัว & สัดส่วน อัปเดตน้ำหนักตัวรายวันเพื่อดูแนวโน้มการลดไขมันหรือเพิ่มกล้ามเนื้อ
หน้าจอแอปจริง • สถิติและความก้าวหน้า
SLIDE 6 • การตั้งค่า API KEY & SYNC

ตั้งค่า Gemini API Key อย่างปลอดภัย

เข้าใจระบบจัดเก็บ Key ฝั่ง Server และฝั่งเครื่อง เพื่อใช้งาน AI ได้อย่างต่อเนื่อง

  • 1
    Server Key (`ScriptProperties`) เมื่อบันทึก Key ผ่านระบบ Google Apps Script ตัว Key จะถูกเก็บอย่างปลอดภัยบน Server และไม่ส่งค่าดิบกลับมาโชว์บนหน้าเว็บ
  • 2
    Local Key (`localStorage`) หากเปิดแอปแบบไฟล์ในเครื่อง สามารถวาง Gemini API Key ในหน้าโปรไฟล์/API เพื่อเรียกใช้งาน Gemini 2.5 Flash ได้โดยตรง
  • 3
    ปุ่มตรวจสอบสถานะ Key กดปุ่มทดสอบเพื่อยืนยันว่า Key พร้อมใช้งาน และดูโควต้า RPM/RPD ได้ทันที
หน้าจอแอปจริง • ตั้งค่าโปรไฟล์และ API
