ติดตั้งแอปลงหน้าจอโฮม (PWA)

WEB APP
ติดตั้งเป็นแอปเต็มหน้าจอบน iOS, Android หรือคอมพิวเตอร์ พร้อมเปิดใช้งานแบบ Offline-First
เปิดผ่าน Google Apps Script อยู่ — จึงยังติดตั้งลงเครื่องโดยตรงไม่ได้
ลิงก์ script.google.com รันหน้าเว็บใน iframe ซึ่งเบราว์เซอร์บล็อกไฟล์ Manifest และ Service Worker หากต้องการติดตั้งเป็นแอปลงมือถือ/คอม ให้เปิดชุดไฟล์หน้าเว็บ (index.html, manifest.webmanifest, sw.js, icons/) ผ่านโฮสต์ HTTPS (เช่น Netlify, GitHub Pages, Firebase Hosting) แล้วกดปุ่มติดตั้งอีกครั้ง โดยข้อมูลจะยังคงซิงก์กับ Google Sheets เดิมได้ทันที

เชื่อมต่อฐานข้อมูล Google Apps Script & Sheets

LOCAL
เปิดตาราง Google Sheets
วิธีเปิดสิทธิ์ Google Sheets ครั้งแรก (ทำ 1 ครั้ง):
1. กดปุ่มเปิด Apps Script Editor ด้านล่าง แล้วลงชื่อเข้าใช้บัญชี Google
2. เลือกฟังก์ชัน authorizeAndSetupSheets ที่แถบด้านบนแล้วกด Run (เรียกใช้)
3. กด Review permissions -> เลือกบัญชี -> Allow (อนุญาต) (หากขึ้นแจ้งเตือนแอปยังไม่ยืนยัน ให้กด ขั้นสูง -> ไปที่โปรเจกต์)
4. กลับมาหน้านี้แล้วกดปุ่ม ซิงก์ข้อมูลกับ Google Sheets
เปิด Apps Script Editor เพื่อกดอนุญาตสิทธิ์
ข้อมูลทุกอย่างถูกบันทึกในเครื่องทันทีแบบ Offline-First และจะซิงก์เข้า Google Sheets อัตโนมัติเมื่อเปิดสิทธิ์การเข้าถึงของ Web App แล้ว
